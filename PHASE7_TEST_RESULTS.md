## Bugs Found and Fixed

### Bug 1: Incorrect Method Name in cli.py

**Location**: `pipeline/traceai/cli.py` lines 409, 666

**Issue**: Called `generate_full_summary()` but method is actually `generate_pr_summary()`

**Error**:
```
AttributeError: 'MarkdownGenerator' object has no attribute 'generate_full_summary'.
Did you mean: 'generate_pr_summary'?
```

**Fix**: Changed all occurrences to `generate_pr_summary()`

**Files Modified**:
- `pipeline/traceai/cli.py` (2 occurrences fixed with replace_all)

---

### Bug 2: Undefined Variable in markdown_gen.py

**Location**: `pipeline/traceai/markdown_gen.py` line 200

**Issue**: Used `user_messages` variable without defining it first

**Error**:
```
NameError: name 'user_messages' is not defined
```

**Fix**: Added line to filter user messages from conversation:
```python
# Filter user messages
user_messages = [msg for msg in self.artifact.conversation if msg.role == "user"]
```

**Files Modified**:
- `pipeline/traceai/markdown_gen.py`
